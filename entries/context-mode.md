## 解决的问题

编码智能体容易被工具输出撑爆上下文：一次日志、一份大文件列表，就把窗口占掉大半，后续推理质量下降，费用却照算。

Context Mode 把工具输出截在外面：先进本地沙箱，需要时再用 SQLite 全文检索取回相关片段。据其 README 的说明，进入上下文的字节数可减少九成以上。

所有数据留在本机，插件不上报遥测。

## 不适用场景

- 上下文窗口本就宽裕的短会话，拦截收益不明显。
- 需要完整保留原始输出以便逐字节比对的调试场景。
