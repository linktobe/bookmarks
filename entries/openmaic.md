## 解决的问题

把一节课做成可交互的形式，成本主要不在讲稿，而在设计与排练：谁讲、在哪一步提问、学生卡住时怎么回应、幻灯片与语音怎么配合。单个模型一次性生成，往往得到一份平铺直叙的讲稿。

OpenMAIC 把课堂拆给多个智能体：主讲、助教、提问的学生各自有角色与上下文，按脚本推进，穿插提问与讨论，最后产出可播放的课堂。清华 MAIC 团队的作品，界面里课程与工作台并列。

## 评分依据

- **开箱即用**：克隆后 `pnpm install`、`pnpm db:up` 起数据库、填好 `.env` 里的模型密钥，`pnpm dev` 即可开课。
- **维护活跃**：最近一次提交于 2026-11-27。
- **文档充分**：README 把前置依赖、配置、起库、开发与生产构建、Docker 部署分节写完。
- **版本规范**：当前版本 1.5.0，三段式版本号。
- **有示例**：未通过。仓库内没有示例课程数据，演示以线上站点与截图呈现。

## 注意事项

要自备模型 API key，课程生成的质量与花费直接取决于所用模型；一次完整课堂的 token 消耗不小。

本地运行要 Node、pnpm 10 以上与一个 PostgreSQL（`pnpm db:up` 用 Docker 起），没有 Docker 时要自备数据库。

生成过程是异步的，长课程要等；中途失败的课程需要重跑而不是断点续。

界面以中文为主，英文文档同步维护，两者偶尔不同步。

## 不适用场景

- 只需要一份讲稿或幻灯片，不需要多角色互动。
- 没有可用的模型额度，或不允许把课程内容发给第三方模型。
