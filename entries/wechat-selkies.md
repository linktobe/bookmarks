## 解决的问题

只有网页版的时候，微信是个能用但残缺的东西：文件传输受限、小程序打不开、多开麻烦。官方 Linux 客户端补上了这些，可它要求一台能跑图形界面的 Linux 机器，服务器上没有显示器，Mac 与 Windows 上也没有对应的包。

WeChat Selkies 把官方 Linux 客户端封进 Docker 容器，用 Selkies 把它转成 WebRTC 流，浏览器里就是一个完整的微信窗口。客户端、文件、聊天记录都在容器卷里，换台机器打开同一个地址就能接着用。

安装是一条命令的事：`docker run` 拉起官方镜像，映射 3001 端口，把 `./config` 挂进容器做持久化，浏览器访问对应地址即可。也有 Compose 写法与源码构建路径。AMD64 与 ARM64 都有镜像，精简版 `minimal` 标签只带微信、不带 QQ 与文件管理器，体积更小。

## 注意事项

容器里跑的是官方客户端，登录行为与桌面端一致。把账号放在远程容器里、经浏览器登录，本身会触发微信的风控判断，长期挂着有被限制的可能，这一点与工具无关，取决于平台策略。

需要 `/dev/dri` 做硬件加速。没有独立显卡或设备节点缺失时，要按文档改软件渲染，否则界面会卡。

端口分工要看清：3000 是 HTTP，3001 是 HTTPS，README 建议用后者。

升级前先读升级说明。版本之间配置结构有变化，直接换镜像而不迁移配置，可能起不来或丢设置。

## 不适用场景

- 需要多开大量账号的批量操作。
- 对聊天记录留存有合规要求的企业环境。
