## 解决的问题

用 AI 做游戏，眼下的形态大多是「对话框里出代码，自己复制到编辑器，再自己跑起来看」。美术、音频、三维、设计稿分散在四五个工具里，改一轮要来回搬运。

OhMyGame 把这些合到一个应用：左边与智能体对话，右边是实时预览，中间的画布同时放设计文档、图像、视频、三维模型、动画、配音、音效与音乐。智能体写完代码会把游戏跑起来试玩，发现问题再改。

产物可以直接发布成链接，别人在浏览器里就能玩；联机游戏的房间、登录、存档与排行榜随发布一起带上。引擎侧预装 Godot、Unity、Unreal、Blender、Aseprite、Tiled 的插件，也能出微信与抖音小游戏。

模型不锁死：自带 Key 可接四十余家提供商，也可以挂到 Claude Code、Codex、OpenCode 上跑；反过来，别的智能体可经 MCP 调用它的画布与媒体生成能力。

## 评分依据

- **开箱即用**：官网提供 macOS 与 Windows 安装包，首次启动接上模型即可开工。
- **维护活跃**：最近一次提交于 2026-11-24。
- **文档充分**：官网文档站另配仓库内运行时、编码智能体、模型与插件契约说明。
- **版本规范**：当前版本 v0.0.0-beta.5.11，以预发布号标注 beta，遵循语义化版本。
- **有示例**：packages 下提供插件范例与游戏模板，可直接跑。

## 注意事项

处于 beta，官方明说会有粗糙的边缘。安装包不含模型，首次启动要接一个提供商或编码智能体，否则只有界面。

发布需要账号，本地项目与 Key 不上传；正式版会发送用量与崩溃报告，可在设置里关闭，源码构建不发。

Windows 包未签名，SmartScreen 会提示。版本号停在 0.0.0-beta.x，接口与工程文件格式仍可能变。

Intel Mac 与 Linux 在路线图上，尚未提供。

## 不适用场景

- 需要稳定的生产级游戏开发流程，不愿承担 beta 期的返工。
- 不使用任何 AI 提供商的离线环境。
