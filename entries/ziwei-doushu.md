## 解决的问题

紫微斗数的排盘涉及安星、四化与诸多流派差异，公开实现多为封装好的黑盒，或只覆盖单一派别，难以核对每一步推导。

该项目以 TypeScript 给出完整排盘算法与四化体系，另附格局知识库与古籍原文数据，供自行检索与比对。仓库同时发布按年份切分的解读数据集，规模与字段在 README 中以表格列出，便于先行评估体积再决定是否下载。

仓库内的界面被作者明确定位为最小可运行示例，用于把引擎跑起来并绘制命盘；线上商业版的界面与解读内容不在开源范围内。

- **开箱即用**：通过。有在线站点可直接排盘；本地运行需 Node，执行 `npm install` 与 `npm run dev`。

## 注意事项

代码为 MIT，数据集为 CC BY 4.0，古籍为公版，但转录的讲课原话注明不可商用。

README 说明开源范围仅限引擎与最小界面；解读面板为占位实现，画得出盘，给不出线上那套解读。数据集解压后体积达数十 GB，下载前应确认磁盘空间。

命理内容属传统文化范畴，不宜作为医疗、投资等决策依据。

## 不适用场景

- 期望直接获得完整解读文字的场景。
- 需要与现代天文历算严格对齐的场合，历法换算仍存在流派差异。
