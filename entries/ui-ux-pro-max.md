## 解决的问题

让智能体做界面，最常见的结果是"能跑但不好看"：配色随手挑、字号没有层级、间距不统一，看起来像默认模板拼出来的。问题不在模型的生成能力，而在它没有稳定的设计依据可查。

UI UX Pro Max 做的事是把设计决策整理成可检索的数据：80 种 UI 风格（其中 51 种在使用中）、194 套按行业对齐的配色、74 组字体搭配、25 类图表建议、22 个技术栈、141 条交互与可访问性准则，另有 194 条按行业生成的推理规则。智能体在做页面之前先检索这些条目，再据此产出设计系统与代码，而不是凭空发挥。

它覆盖的宿主很广：Claude Code、Cursor、Windsurf、Copilot、Codex、Gemini CLI、Kiro、Trae、Qoder、Roo Code、OpenCode、Continue、Warp 等二十余种，装一次就能在选定的宿主里用。

## 注意事项

免费版与付费版有明确的功能分界，README 里有对照表。仓库这一份是基础版，配色、字体、规则这些静态数据齐全，但按 README 的描述，部分行业推理与生成能力留在付费版。

它产出的是设计决策与代码片段，不是可直接运行的成品应用。最终效果仍取决于宿主模型的实现能力，以及检索到的条目是否切题——行业选错、风格选错，拿到的仍然是漂亮但不对的东西。

八种语言的 README 内容并不完全同步，以英文版为准。

## 不适用场景

- 已经在用成熟设计系统、只需要实现规范约束的团队。
- 不使用任何编码智能体、纯手工写样式的场景。
