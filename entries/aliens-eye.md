## 解决的问题

同一个用户名往往散落在几十个平台上，人工逐个试既慢也记不住哪些站有过。社工库不可靠，公开检索又需要知道站点清单。

Aliens Eye 维护一份七千多个站点的清单，按用户名做并发探测，用规则与模型区分「确实存在此用户」与「页面长得像但只是通用模板」，结果可按站点、标签与置信度过滤，支持导出 JSON、CSV 与 PDF，也能作为 MCP 服务被 agent 调用。

## 注意事项

它查的是「这个用户名在哪些站出现过」，不是「这个人是谁」；同名不同人是常态，结论只能当线索。

站点会反爬与限流，高频扫描容易触发验证码或封 IP；工具给了代理与 Tor 选项，可用与否取决于你的网络环境。

部分站点需要登录才能确认，未登录时结果会被标成低置信度。

README 带赞助商链接；用于对他人做画像时，注意所在地法律对个人信息收集的限制。

## 不适用场景

- 需要实名身份、手机号或邮箱反查的场景。
- 不允许向大量第三方站点发起请求的环境。
