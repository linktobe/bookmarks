## 解决的问题

把 agent 放进桌面之后，麻烦集中在三处：一次只能干一件事；权限要么全开要么全关；聊天与文件被传到厂商服务器。

PiBot 让几个命名 bot 同处一个群聊，各自带模型、技能、权限与记忆，也能把活转交给彼此。每次工具调用过一个统一的策略引擎，命令在受限环境里执行，审批、执行过的命令与对外发送的内容都写进审计日志。模型可接 Ollama 本地模型、OpenRouter 或自备 API key，README 声明自家服务器不接收聊天与文件。

## 注意事项

很新：2026-11-21 建库，当前 0.0.3，功能与设置项都在快速变动，遇到问题先看 Issues 是否已有人报。

电脑操作类功能要系统权限（屏幕录制、辅助功能），首次启动需逐项授予，拒绝其中一项相应能力就不可用。

本地模型要自己装 Ollama 并下载权重；用云端模型时，发出去的提示词由所选提供商经手，隐私边界到那里为止。

审批是最后一道闸，连点确认仍会放行危险命令。

从源码跑需要 Node 与 pnpm 12，`pnpm dev` 启动的是开发版，数据目录可用 `PIBOT_DATA_DIR` 与已安装的版本隔开。

## 不适用场景

- 需要接口长期稳定的生产环境。
- 机器内存很小，或没有独显却要跑本地模型。
- 完全隔离、不允许任何联网模型的场合。
