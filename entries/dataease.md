## 解决的问题

做一张能给别人看的业务看板，通常要凑齐三样东西：一个连得上的数据源、一套画图表的库、一个能把成品发出去的地方。自己写要一个前端，买商业 BI 要一笔授权费，而多数需求其实只是把几张表拼成一个页面。

DataEase 把这三件事收进一个可以装在自己服务器上的应用。数据接入支持两种模式：直连直接查库，本地模式把数据抽进 Apache Doris，换取大数据量下的秒级返回。图表用 ECharts 与 AntV，仪表板靠拖拉拽拼，不需要写代码。成品可以在 PC、移动端与数据大屏三种形态下展示，分享方式也给了几种。

README 列出的数据源覆盖面比较宽：MySQL、Oracle、SQL Server、MariaDB、ClickHouse、Doris、StarRocks、TiDB、PrestoDB、Hive、MongoDB、Elasticsearch、Redshift、DB2、Kylin 这些常见库，加上 Excel 文件、API 接口，以及达梦、人大金仓这类国产数据库。

安装只要两步：一台不小于 8 G 内存的 64 位 Linux 主机，以 root 执行一条安装脚本。不想装也能先看，官方给了一个 demo 账号的在线环境。

## 注意事项

许可是 GPL-3.0。自用与内部部署不受影响，但把它并入自家产品对外发行，会触发传染条款；商业闭源集成需要单独评估。

一键安装脚本从网络上取内容并以 root 身份执行，安装前建议先把脚本取下来看一遍，尤其是装在生产机器上时。

README 里的在线文档链接指向 v1 目录，而首页自己也注明 V1 社区版已停止维护；当前发布版本已是 v3.3.1，查文档要走新版入口，照 v1 文档配置会遇到与当前界面不一致的地方。

本地模式会额外拉起 Apache Doris，内存与磁盘占用明显高于直连模式。8 GB 只是安装门槛，数据量上去之后需要留出更多余量给 Doris。

在线体验环境的账号是公开的 demo 与 dataease，任何人都能登录，不要在那里放真实数据。

## 不适用场景

- 要把图表嵌进自家产品、且要求闭源分发的团队。
- 只做一次性小统计、不值得架一套服务的场景。
