## 解决的问题

USB-C 接口外形一致，能力却差得远：同一根线可能只支持 USB 2.0 的四百多兆，也可能跑满四十吉比特；同样的口，供电从六十瓦到二百四十瓦不等。线材没有丝印标功率，用错线往往表现为「硬盘变慢」「显示器点不亮」，很难联想到线上。

WhatCable 读系统的 IOKit 报告，把线材与接口的能力翻成人话：数据速率、供电档位、是否支持 Thunderbolt 与视频输出，并说明为什么你的 Mac 在掉电或降速。

## 评分依据

- **开箱即用**：`brew install --cask darrylmorley/whatcable/whatcable`，或用发行页的 zip；插上线即可在菜单栏看到读数。
- **维护活跃**：最近一次提交于 2026-11-26。
- **文档充分**：README 讲清每项读数的含义、CLI 用法与从源码构建的步骤，另有独立文档站。
- **版本规范**：当前版本 1.5.1，三段式版本号，图形包与 CLI 包同版发布。
- **有示例**：未通过。仓库没有示例数据或演示工程，截图与站点在仓库之外。

## 注意事项

只有 macOS 版本，读的是 Apple 平台的 IO 报告；Windows 与 Linux 上没有等价实现。

读到的是接口与线材协商后的能力，线材本身若未做 e-marker 标记，部分字段会显示未知，这是硬件限制而非软件缺陷。

许可为混合授权：仓库根目录是 MIT，个别子目录带自己的 LICENSE（插件目录为专有），二次使用前要逐目录确认。

菜单栏常驻应用，权限上需要读取系统硬件信息；不想常驻时可用 CLI 版本按需调用。

## 不适用场景

- 非 macOS 环境。
- 需要检测劣质线材的电气参数（它读的是协商结果，不做测量）。
