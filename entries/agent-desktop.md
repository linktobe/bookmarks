## 解决的问题

让智能体操作桌面软件，常见做法是截图加坐标点击：分辨率一变、主题一换就失效，还看不出控件到底是什么。

agent-desktop 改读系统的无障碍树，把当前界面还原成带引用的 JSON：每个可操作元素有稳定的标识，智能体按标识点击或输入，然后重新读一次界面确认结果。整个循环留在智能体里，这个工具本身不含模型。

它同时提供命令行与 C 库，方便接进不同的运行时。

## 注意事项

macOS 需手动授予辅助功能权限，Windows 与 Linux 的权限模型不同，跨平台行为并不完全一致。

无障碍树的信息完整度取决于应用有没有正确实现：自绘界面、游戏与远程桌面通常拿不到可用节点，需要回退到视觉方案。

## 不适用场景

- 目标应用没有无障碍支持，方案会退化成盲操作。
- 需要精确视觉判断的场景，读树拿不到画面细节。
