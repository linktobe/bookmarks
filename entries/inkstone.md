## 解决的问题

配色主题多数是在暗色底上随手挑几个高饱和颜色，切到亮色就散架。墨观的做法是先定骨架再定颜色：强调色的色相顺序固定为朱、蓝、绿、橙、紫、青、绛，六个变体只换光线与饱和度。

颜色不是随便取的，来自五百二十六个中国传统颜色——关键字用朱砂系，字符串用铜绿或竹绿，类型用土黄或紫色系，中性色是墨、纸、深海与青瓷釉。红色只做记号（关键字、标签、错误、删除），青色统一表示可交互（按钮、徽标、进度、焦点）。

一致性由生成器保证：一份语义色板同时产出 VS Code、Ghostty、Kaku、WezTerm、OpenCode、Zed 与 DeepSeek Harness 的主题，构建时会拒绝落在对比度区间与彩度预算之外的配色。暗色的降光版本画布更沉，正文对比度仍在 10.5:1 以上。

六个变体是玄墨、玄墨 Dimmed、宣纸、宣纸 Dimmed、沧海与青瓷。VS Code 系可从应用市场或 Open VSX 安装，也能直接下 VSIX。

## 评分依据

- **开箱即用**：应用市场装扩展后切换配色即生效，终端与其它编辑器亦有安装脚本。
- **维护活跃**：最近一次提交于 2026-11-16。
- **文档充分**：docs 下分设计约束、色板对照、安装详解、开发与发布五篇。
- **版本规范**：当前版本 v0.6.0，遵循语义化版本并附变更记录。
- **有示例**：showcase 用同一份代码样张渲染六个变体，可本地构建查看。

## 注意事项

六个变体中只有玄墨与宣纸各有完整的光线与降光配对，沧海与青瓷各只有一个明暗面，想凑齐明暗切换要跨组搭配。

终端主题要先 pnpm install，再按目标跑 install:ghostty、install:kaku 或 install:opencode 等；脚本会先构建再复制到对应配置目录，旧版 Kaku 与 WezTerm 走 Lua 而非 TOML。

配色偏克制，习惯高饱和主题的人会觉得发灰。传统色名属公共文化资产，仓库只对代码主张 MIT。

版本 0.6.0，主题命名与色值仍可能微调。

## 不适用场景

- 需要每套配色都单独精调、不接受统一色相骨架。
- 使用未列入支持清单的编辑器或终端。
