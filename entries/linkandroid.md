## 解决的问题

把安卓手机接到电脑上，散落着一堆小工具：投屏用 scrcpy，传文件用 adb 或文件管理器，录屏再找一个，跑脚本又是另一套。命令行够用，但不适合演示与重复劳动。

LinkAndroid 把这些收进一个应用。连接方式给了五种——USB 自动识别、无线扫码、六位配对码、IP 直连、局域网 mDNS 发现；多台设备可同时在线并分组管理。

投屏基于 scrcpy，可反控、可走 OTG 模式把电脑当键鼠、可调码率帧率，也能直接调手机摄像头当画面源。截屏后自带加边框与渐变背景的美化，录屏可出 MP4 或 GIF。文件管理与应用管理是常规表格操作，内置 ADB Shell 与常用命令面板。

比较实用的是脚本自动化：内置 Python 编辑器，可写脚本、按 Cron 定时、选多台设备同时执行、查看历史日志；对外还开了 HTTP 接口（默认 53070 端口，Bearer Token 认证），可从 CI 或其它系统触发。另有四十余家模型提供商的接入，用于在编辑器里让模型代写脚本。

## 注意事项

无线配对依赖安卓 11 以上的无线调试，更低版本只能走 USB。仓库内是源码，本地开发只在 Node.js 24 下验证过；普通使用直接装官网安装包即可。

HTTP 接口默认在本机监听，暴露到局域网前先确认 Token 与防火墙规则。脚本在电脑侧执行，通过 adb 驱动手机，手机端不需要装任何东西。

内置的模型接入只是辅助写脚本，费用由各自 Key 结算。

## 不适用场景

- 只需要一条 adb 命令的场合，装整个应用反而更重。
- 需要 iOS 设备投屏。
