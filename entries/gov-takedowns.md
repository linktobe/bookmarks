## 解决的问题

平台被要求删内容时，用户通常什么也看不到。这个仓库是 GitHub 的透明性档案：把收到的政府下架通知按国家分目录存档，正文照录，标明时间与范围。

按国家分目录的做法让「哪一类请求在哪个司法辖区出现」变得可比：同一时期的请求，有的针对具体仓库，有的针对整类内容；有的附法律依据，有的只有一句话。

## 评分依据

- **开箱即用**：纯数据仓库，克隆或在线点开对应国家目录即可阅读通知原文。
- **维护活跃**：最近一次提交于 2026-11-24。
- **文档充分**：README 说明通知的来源、呈现方式与收录范围。
- **版本规范**：未通过。仓库没有发布版本标签。
- **有示例**：未通过。目录内即为通知原文，不含示例工程。

## 注意事项

仓库没有许可声明，不能按开源许可转载或再分发；引用原文时按「GitHub 政府下架通知存档」注明来源与日期。

只收录 GitHub 收到的通知，不覆盖其他平台，也不含被删除内容本身——通知里描述的对象多数已经不存在，研究时要另找存档。

政府要求删除不等于内容违法，也不等于 GitHub 已执行；部分通知被提出异议后撤回，仓库里仍是原文。读的时候要分清「请求」与「结果」。

## 不适用场景

- 需要被删内容原文与恢复快照。
- 需要跨平台的统一下架统计。
- 需要可直接再利用的数据集授权。
