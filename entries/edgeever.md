## 解决的问题

笔记软件的选择往往卡在两处：老牌产品的数据进了别人的数据库，导出只剩半截结构；新一代工具又常把 AI 做成订阅功能，笔记要先传上云才能用。

EdgeEver 保留经典三栏（目录树、笔记列表、编辑器）的高效路径，数据放在自己控制的 Cloudflare Workers 或 Docker 容器里，客户端覆盖桌面、移动与浏览器剪藏，AI 能力通过 MCP 接入，任何支持 MCP 的 agent 都能读写而不是被某一个模型锁住。

## 评分依据

- **开箱即用**：发行页提供 Windows、macOS、Linux 桌面安装包；自托管可选 Docker 一条命令，或点一下部署到 Cloudflare。
- **维护活跃**：最近一次提交于 2026-11-27。
- **文档充分**：README 把客户端下载、剪藏扩展、三种部署方式、备份迁移与 MCP 接入分节写全。

## 注意事项

自托管要先准备好 Cloudflare 账号与 D1 数据库，或一台能跑容器的机器；本地起服务仍需要 `.env` 里的密钥配置。

多端同步依赖你自己的服务端，服务不可达时客户端能离线写，但冲突处理比同端编辑更粗糙。

AI 功能走 MCP，需要另配 agent；不接 agent 时它可以当作纯笔记应用使用。

AGPL-3.0，二次分发或对外提供修改版服务时要注意开源义务。

## 不适用场景

- 只想装在本地、完全不想要服务端与账号体系。
- 需要严格的团队权限模型与审计。
