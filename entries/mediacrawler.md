## 解决的问题

各内容平台的访问方式、登录态与数据结构互不相同，逐一实现采集的成本很高，且平台改版后需要重复维护。该项目将七个平台收敛到同一套命令行入口，按平台、关键词或指定 ID 采集笔记、视频与评论，并可选启动本地 API 服务供其他程序调用。
