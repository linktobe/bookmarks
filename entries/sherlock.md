## 解决的问题

想知道一个用户名在哪些平台注册过，人工逐个去试既费时又容易漏；站点清单靠记忆维护，过一阵就过期。

Sherlock 维护一份持续更新的站点清单，按用户名并发查询，按「存在 / 不存在 / 未知」分类输出，支持导出 CSV、JSON 与文本，也能只查指定站点或用 Tor、代理绕开限流。它是这类工具里最常被引用的一个，二〇一八年至今仍在维护。

## 评分依据

- **开箱即用**：`pip install sherlock-project` 之后 `sherlock 用户名` 即可，几秒到几十秒出结果。
- **维护活跃**：最近一次提交于 2026-11-27。
- **文档充分**：主说明放在 `docs/README.md`，安装、用法、站点清单与输出选项都写了。
- **版本规范**：当前版本 0.16.2，三段式版本号，PyPI 与仓库同步。
- **有示例**：未通过。仓库里是测试与站点数据，没有可运行的示例。

## 注意事项

仓库根目录现在没有 README，说明搬进了 `docs/README.md`，从旧链接进来会以为是空仓库。

查的是用户名占用情况，不是身份归属；同名不同人是常态，结果只能当线索。

站点会限流或返回验证页，「未知」不等于「不存在」；被大量请求时自己的 IP 也会被挡。

用于对他人做画像时，注意所在地法律对个人信息收集的限制。

## 不适用场景

- 需要邮箱、手机号反查。
- 不允许向大量第三方站点发起请求的环境。
