## 解决的问题

公众号不能放自动播放的视频，也不让跑 JS，可读者是往下滑着看的。想让内容「自己长出来」——线稿自绘、数字滚动、等轴测小场景一块块拼好、照片从磨砂变清晰——只剩 SVG 动画一条路。

麻烦在于微信会把 SVG 里的大部分东西删掉。这个仓库最值钱的部分不是模板，是 `docs/wechat-svg-rules.md` 那份清单：所有 id、`fill-opacity` 动画、`xlink:href`、滤镜、渐变、mask、clipPath、style 与 JS 都会被删；插音频整篇拒收；而 `animate`、`animateTransform`、点击触发与微信图床图片可以保留。每一条都是推进草稿箱、再拉回来逐个标签比对出来的。

产出分四条路：套模板（十四种场景、六套配色）、等轴测 3D 旅程（流程、路线、几站串起来的故事）、品牌 VI 版（磨砂玻璃立板、清晰窗由虚到实、标尺测量线、VI 字体转曲）、以及把已有成片改编成长图（七步流程加自带工具包，没有素材也能先跑通）。

## 注意事项

推送草稿箱要先把本机公网 IP 加进公众号后台白名单，第一次推会提示是哪个 IP。填了 AppID 与 AppSecret 才能推，不想填就走粘贴台一键复制。

发布永远由自己点。工具只负责推进草稿箱并拉回来比对，不代替发布。

它同时是一个 Agent Skill，丢给 Claude Code、Codex 或 Cursor 让它先读 SKILL.md 即可；也能纯命令行跑，两条路互不依赖。截帧检查与封面生成要另外装 Playwright 的 Chromium。

授权分两块：代码 MIT，示例分镜里的文案归作者，改模板时注意别把示例文案一起搬走。

## 不适用场景

- 没有公众号，或内容需要视频与交互。
- 需要公众号后台之外的排版能力。
