## 解决的问题

agent 常见的毛病是没看事实先给结论：拿到一句话就开始写，遇到冲突就两边和稀泥，做不完也说做完了。提示词里写「要严谨」没有用，缺的是可执行的步骤。

这个技能从唯物辩证法与实践哲学里提炼出一条总原则与九件工具：先调查再判断、抓主要矛盾、在实践中检验、不达目的不罢休等，每件工具都给触发条件与操作步骤，装进 agent 后按场景调用，也能手动唤起。

## 注意事项

效果依赖宿主模型的理解力，规则写得再细，模型不照做时仍会退回到「先给答案」。

安装脚本会改写 agent 的配置目录，支持的目标不少（Claude Code、Cursor、Codex、OpenCode 等），装前看清 `--target` 与 `--scope`。

它是一套方法论提示，不是评测基准；是否变好需要自己拿同一批任务对照跑。

文本带较强的政治语汇，用于对外产品时要注意语气是否合适。

## 不适用场景

- 需要可量化的评测与回归测试来证明提升。
- 需要与具体业务规则绑定的合规流程。
