## 解决的问题

虚拟主播的形态——Live2D 或 VRM 模型加实时语音加人格设定——过去是一整套定制工程：动作捕捉、语音链路、对话逻辑、直播推流，各写一遍。

Project AIRI 把它收成一个可自托管的容器。模型层支持 Live2D 与 VRM；桌面端 Windows、macOS、Linux 都有安装包，浏览器打开即用，移动端另有入口。

语音是实时链：麦克风输入经语音识别转文字，交给语言模型，再用语音合成回放，配合口型与表情驱动。记忆系统保存对话与设定，让角色跨会话保持一致。它还能进 Minecraft 与 Factorio 里活动，把游戏当成可交互的环境。

模型侧不绑定厂商，可接云端提供商，也可接本地推理。仓库是 monorepo：舞台应用、组件调用、UI 服务与若干插件（B 站直播、Claude Code 桥接、国际象棋、浏览器扩展）分处不同包，界面文案做了八种语言。

## 注意事项

仍是 0.x，包结构与接口会随版本调整。实时语音对延迟敏感，语音识别与合成最好放本地或就近区域，跨洋调用会明显卡顿。

默认不带模型与语音服务，需要自己配 Key 或起本地推理，第一句对话之前的配置量不小。

角色卡、Live2D 模型与音色各有自己的授权，商用前逐个确认。插件生态还在早期，可用插件数量有限。

## 不适用场景

- 只需要文字对话，用普通聊天客户端更省事。
- 追求开箱即用的完成度，不愿折腾模型与语音链路。
