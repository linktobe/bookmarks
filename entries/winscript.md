## 解决的问题

网上的 Windows 精简脚本多是别人写好的一整份，里面有什么只能通读一遍才知道，想只去掉某几项就得自己改代码。改错了轻则功能异常，重则系统起不来。

WinScript 把这层改成可选：在图形界面里按类勾选——精简（去预装应用与组件）、隐私（关遥测与数据收集）、性能（调服务与调度）、应用安装（批量装常用软件）、无人值守安装（生成应答文件）——勾完导出成一份 PowerShell 脚本，或者直接导入一份已有的配置文件继续改。

产出的脚本可以留档、可以逐行审阅、也可以交给别人复现同一套配置。运行方式有三种：`irm` 一行直接在内存里执行、`winget install winscript` 走包管理器，或者下载可执行文件带 `-i` 参数导入配置。

## 注意事项

脚本会改注册表、停服务、卸组件。执行前建一个系统还原点，比事后找原因省事得多。

`irm | iex` 的写法是从网络直接取内容执行，没有中间落盘的机会，也就没法先看一眼。介意的话改用 winget 或下载文件后再审阅。

企业或域管理的机器上，部分项会被组策略覆盖，脚本跑完看着成功，实际未生效；此时要到策略层面处理。

精简与稳定之间存在取舍。去掉某些组件之后，后续的累积更新或某个依赖它的软件可能报错，出问题时需要逐个回滚排查。

## 不适用场景

- 生产环境的服务器机器。
- 需要长期稳定、不接受任何系统层改动的办公电脑。
