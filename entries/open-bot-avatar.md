## 解决的问题

给智能体一张脸，通常有两条路：找一套现成的角色图，改不动；或者自己画一套，成本高，还很难在多个状态上保持一致。而在对话界面里，这张脸还要表达状态——正在思考、在干活、被卡住、做完了。

Open Bot Avatar 把这件事拆成一个规范加一个渲染器。规范只有一项：一个 0 至 100 见方的 SVG 路径，加上眼睛的位置、间距与大小。渲染器据此推断体积——把轮廓切成一层层横截面再投影——活动的头像每帧画到 canvas 上，静帧输出一张 SVG，另有一个基于 CSS 3D 的 scene 模式，一层横截面一个 SVG。

状态是接口的一部分：idle、thinking、working、waiting、blocked、done 六种，配 neutral 与 happy 两种情绪；followPointer 让它盯着鼠标或手指，material 可在 flat 与 fluffy 之间切换，depth 控制体积，reducedMotion 跟随系统设置。

生成也交给模型：编辑器里有 Generate，把描述发给任意聊天模型，把返回的 JSON 粘回 Import 即可；仓库另附一份系统提示词与一个技能，装了技能的智能体可以直接产出合法定义。做完可以提交到 gallery，成为别人也能用的一份。

## 评分依据

- **开箱即用**：通过。一条 pnpm 命令装上即可挂载，零依赖；另有在线编辑器可直接试。
- **维护活跃**：最近一次提交于 2026-11-23。
- **文档充分**：README 给出定义格式、挂载接口、全部选项与 SVG 输出三组用法。
- **版本规范**：npm 上当前版本 0.4.0，遵循语义化版本并持续发布。
- **有示例**：通过。gallery 目录内含十七份可直接载入的成品头像定义。

## 注意事项

体积是从轮廓推断的，形状越怪，横截面越容易露馅；闭环多、凹陷深的路径要自己试着调 depth。

仍处在 0.x。接口已经稳定到可以日常使用，但按语义化版本的约定，小版本号变动仍可能带来破坏性改动，锁版本比追最新稳妥。

模型生成的定义必须过一遍 validateAvatar。坐标越界、路径指令非法是最常见的两类错误，校验器会给出具体到字段的报错。

包只提供 DOM 挂载与 SVG 输出两条路径，React、Vue 之类的框架绑定要自己包一层。文档与界面均为英文。

## 不适用场景

- 需要写实人像或复杂插画的头像。
- 只想要静态图、不打算接入状态的展示场景。
