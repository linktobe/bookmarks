## 解决的问题

背单词软件的通病是抽象：一个英文词配一行中文释义，释义记住了，见了实物仍想不起来。图像记忆的道理人人都懂，可给七千个词逐一手绘，成本不现实。

词光用生成式模型把这件事做了：七千二百九十八个词条，每条一幅插画、中英释义、两条原创例句，外加搭配、词族与易混提示。全部词条都有英音、美音与例句朗读，一千零一十一个重点词另配第二条例句录音。

学习侧是四个动作：看画面与释义（看见）、切英音美音（听见）、用看图补句与听音辨词做主动回忆（想起）、交给 FSRS 安排复习（复习）。十九个话题排成一张星图，学过的词按亮度区分，可拖拽旋转、滚轮缩放，用 WebGL2 渲染，不支持的设备降级显示。

仓库提供的是开源基础版：React 19 加 Vite 的静态应用，不要账号，进度存在本地。词库以 JSON 与 CSV 两种格式开放，插画是 512 像素 WebP，另有缩略图。

## 评分依据

- **开箱即用**：在线版打开即用；本地 clone 后 npm ci 与 npm run dev 即可起。
- **维护活跃**：最近一次提交于 2026-11-13。
- **文档充分**：README 交代学习流程与本地运行，docs 另有数据集、生成管线与记忆模型。
- **版本规范**：App Store 上的词光为 1.1.3，遵循语义化版本；仓库本身未打标签。
- **有示例**：未通过。data 为词库数据本体，仓库不含独立示例。

## 注意事项

仓库带全部插画与录音，约 650 MB，首次 clone 与 npm ci 都比较慢。

内容是模型生成的，经过自动结构与一致性校验，但没有逐条人工审校。README 自己写明可能出现释义、例句、插画或发音错误，也不是官方雅思词表，不承诺提分。

授权是分开的：应用代码 MIT，词库文本、插画与词条录音按 CC BY 4.0 开放，署名要求是 Word Atlas contributors。拿去训练或做 Anki 牌组都行，署名不能省。

开源版、线上站点、iOS 版不是同一套。README 说明在线站独立迭代，功能可能与仓库不同。

进度只存在本机，换设备前要先导出备份。

## 不适用场景

- 需要官方词表与逐条权威释义。
- 需要班级管理、教师端与跨设备同步。
