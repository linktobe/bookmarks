## 解决的问题

准备一门考试，材料散在 PDF、笔记、错题截图与单词表里：读的时候在阅读器，记的时候在笔记软件，背的时候在卡片应用，复习节奏还得自己排。工具之间的搬运比学习本身更耗神。

DeepStudent 把十二个学习应用装进一个桌面端：文档阅读与文献管理、笔记、题集、闪卡、思维导图、RAG 检索、间隔重复排程（FSRS）等，由学习 agent 串联，数据存在本地目录，可导出。

## 评分依据

- **开箱即用**：发行页提供 mac、Windows、Linux 与 Android 安装包，装上即可导入文档开始读。
- **维护活跃**：最近一次提交于 2026-11-27。
- **文档充分**：README 分节写清十二个内置学习应用、数据存放、安装与开发者架构。
- **版本规范**：当前版本 0.20.11，三段式版本号，六个平台的包同版发布。
- **有示例**：examples 目录下有四个社区插件示例，按清单写、可在本机加载测试。

## 注意事项

版本号还在 0.2 以下，数据格式与插件接口会变；升级前先备份数据目录。

模型要自己配：本地模型走 Ollama 一类，云端要填 API key，读长文档时的花费取决于所选模型。

间隔重复用的是 FSRS，参数默认值适合一般复习强度，备考冲刺要自己调。

AGPL-3.0；插件体系依赖其宿主 API，写插件需读 docs 里的 SDK 说明。

## 不适用场景

- 手机为主、桌面很少打开的学习场景。
- 需要多人协作与班级管理的教学场合。
