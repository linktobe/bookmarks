## 解决的问题

网页里那些「跟着滚动展开」的动画，难点不在写事件监听，而在素材：产品爆炸图、镜头穿越、角色转头，都需要逐帧连续的画面，靠 CSS 与 SVG 做不出来，靠逐张生成又对不齐。

Oil Motion 把这套流程交给智能体：先设计动作节奏，再生成连续画面，整理成可随滚动、鼠标、拖动或设备倾斜推进的资源，最后写进页面。

README 划的边界很清楚：只适合主体本身需要变化的动画；按钮反馈、布局过渡这类用 CSS 就能做的，不该走这条路。

## 注意事项

动画素材由生成模型产出，风格与连贯度随模型波动；一次不满意通常要重做整段，而不是改几行代码。

连续画面意味着体积：几秒钟的逐帧素材可能比整页其他资源还大，移动端尤需压缩与懒加载。

## 不适用场景

- 纯界面过渡与按钮反馈，用 CSS 更快更小。
- 需要与真实 3D 模型实时交互的场景，预渲染序列替代不了。
