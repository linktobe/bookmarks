## 是什么

支付宝面向智能体生态做的 Skill 交易平台。两侧各有一个入口：创作者提交 Skill，平台先做安全检测，通过后成为商品；消费者在 Agent 里选购，确认价格后用支付宝「AI 付」付款，拿到一段履约口令，交给 Agent 执行即可完成安装。

付费分两种。买断制交付 Skill 明文，可下载 ZIP 包；订阅制只给当期使用权，交付的是影子 Skill，明文不外流，也不会自动续费。PC 端与小程序都能下单，网页支付和扫码支付并存。

官方点名体验较好的宿主是桌面端的 WorkBuddy、豆包工作、千问办公、Cursor、Codex，以及本地框架 Claude Code。更新日志显示迭代很快：八月起发博客，九月上线网页支付，十一月初上小程序与 ZIP 下载，十一月中把登录授权码与付款码合并成一个码，全部操作可在手机上完成。

## 解决的问题

写 Skill 的人有个共同困境：好用的东西传出去，除了收 Star 没有别的回报；而愿意付钱的人，也找不到一个能安全交付的地方。

SkillPay 补的是中间那一段：计价、支付、交付、退款、侵权下架。钱按官方说法是实时进入创作者的支付宝账户，不经平台中转、不用等结算；退款由双方先协商，确认后创作者在产品页手动发起实时退款，订阅单整单全退。

对消费者而言，它解决的是「装」的问题。付款后不必自己找仓库、解压、拷目录，把口令发给 Agent 就装好了。

## 注意事项

履约依赖 Agent 往本地沙盒里写文件，官方建议至少开放文件写入权限，并允许它在需要时请求操作批准。Windows 上另有几处坑：PowerShell 受限语言模式、部分目录的写权限、Git Bash 缺失，各自会让安装停在半路，常见问题里给了对应绕法。

支付走支付宝「AI 付」，实质依赖大陆支付宝账户；外币结算与海外用户如何付款，页面没有说明。

平台对 Skill 做的是安全检测，检测通过不等于逐条审过内容。退款要先与开发者协商，平台不垫付。侵权投诉走邮箱，处理方式是核实后下架。

订阅制拿到的是影子 Skill，看不到明文，既不能自行修改，也依赖平台持续可用。

## 不适用场景

- 需要许可清晰、可自主托管的商业采购。
- 没有支付宝账户，或不在其支持地区。
