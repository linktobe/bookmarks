## 是什么

一间为 ESP32-S3 开发板准备的工作台指南，四个动作串起全站：接线、烧录、观察、读代码。

实验共三十二个，分在六条路线上：入门三节（准备、你好、第一个电路）、显示与输入、Wi-Fi、RFID 与 NFC、低功耗蓝牙、声音，另有一条传感器路线标着「即将推出」。

首页先问「你的工作台上有什么」：勾选手头有的元件——LED 与限流电阻、按钮、1.9 英寸 ST7789 屏幕、RC522 读卡器、MIFARE 卡、2.4 GHz 网络、智能手机、INMP441 与 KY-037 两支麦克风、MAX98357A 功放与扬声器——能做的实验会立刻亮起来，只差一个元件的会写明还缺什么。

每节课四个部分：目标、接线（一张引脚编号完整的板图，配起点与终点的对照表）、步骤（可逐条勾选的清单）、预览（串口监视器里实际会出现的输出）。另有「读代码」视图，对照固件源码看这一课写了什么。

烧录走 PlatformIO 加 uv，命令形如 `uv run pio run -d labs/02-led -e 02-led -t upload -t monitor`，每节课给出可直接复制的那一行。另有数据手册与工作台两页可查。

## 解决的问题

拿到一块新开发板，卡点很少在代码，多在两件小事上：这根线该接哪个脚，这次的实验手上的零件够不够。芯片手册按引脚编号编排，教程按功能编排，两边对不上；买齐一套教程的零件，往往有一半用不上。

这个站把「我有什么」放在最前面。勾一遍元件，剩下的实验自动分好类：现在就能做的、只差一个元件的、缺得还多的。省掉的是一次买错零件的钱和做到一半发现少一颗麦克风的时间。

预览那一节值得单独说：它给的是串口监视器里的真实输出，烧之前就知道烧完屏幕上该出现什么。接线表也写真话——改接线前先拔 USB，写入期间别拔线，要把引脚从输出改成输入就先烧录再接线；另有一张「可放心使用的 GPIO / 避免使用」对照。

## 注意事项

面向的是一块具体的板：ESP32-S3 WROOM-1 N16R8。引脚图按乐鑫 DevKitC-1 v1.0 绘制，兼容板基本一致，但页面上自己也提醒以开发板上印的标注为准。换 ESP32 经典款、C3 或 S2，这套实验不通用。

三十二个实验里只有一部分标着「已在开发板上运行」，其余标「已构建，未烧录」——代码写好也编过了，但作者还没在真板上跑过。看到后一个标记，出错时先怀疑示例，再怀疑自己的接线。

元件勾选与完成进度都存在浏览器本地，换设备或清缓存会丢。
