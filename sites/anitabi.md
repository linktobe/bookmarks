## 是什么

一个圣地巡礼的地图站，把动画中出现的场景标到真实坐标上，每个点配动画截图，可对照实景。主界面支持按作品、地名、城市检索，点击空白处可投稿新的地标。周边工具分几块：都道府县巡礼制霸等级（在自己浏览器里记录去过哪些县，可生成分享图）、调色对比生成器（提取动画截图的影调与配色，套到实景照片上，在 compose.anitabi.cn）、对比图生成器（在线拼动画与实景，在 lab.magiconch.com/image-merge）、iOS 测试版（TestFlight）。另有面向非商业项目的公开 API 与给番组计划用的取景地标组件，制作者署名神奇海螺试验场。

## 解决的问题

巡礼信息原本散在个人博客、攻略与论坛里，一篇讲一个作品、一张图配一段碎碎念。地图化之后问题变成可查询的：这部动画在这座城市有哪些取景地，彼此多远，先看哪个。对做旅行计划的人，这是把「想看」落成路线的那一步。

## 注意事项

数据靠用户投稿，热门作品覆盖较全，冷门作品的点位可能只有几个，坐标也可能偏出几十米。公开 API 只允许非商业、非盈利项目调用，商用要另行联系。制霸等级与进度存在浏览器 localStorage 里，清缓存或换设备就没了。iOS 版走 TestFlight，有九十天的构建有效期，过期要等新版本。地图底图与截图版权分属各家，转载要看清来源。

## 不适用场景

- 需要官方行程、交通与住宿方案。
- 需要中文配音讲解或导览音频。
- 需要覆盖非日本地区动画的完整数据。
